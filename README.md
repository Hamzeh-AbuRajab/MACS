# MACS – نظام إدارة الأصول العسكرية

**منصة الإدارة العسكرية وإدارة الأصول والموارد**

## نبذة عن المشروع

MACS هو نظام إلكتروني مصمم لتنظيم وإدارة الأعمال الإدارية والعسكرية، وإدارة الأفراد والرتب والأقسام والمستودعات والموارد والعمليات الداخلية.

يهدف النظام إلى توفير منصة مركزية لوزارة الدفاع، تتكون من موقع عام لعرض الأخبار والإعلانات والقرارات والقوانين، وبوابة داخلية آمنة لإدارة شؤون الوزارة.

## المميزات الرئيسية

- **الموقع العام:** عرض الإعلانات الرسمية والقرارات والقوانين والأخبار ومعلومات الأقسام.
- **تسجيل الدخول:** الدخول باستخدام حسابات ينشئها المسؤول.
- **نظام الصلاحيات:** تحديد صلاحيات كل مستخدم حسب دوره ومسؤولياته.
- **إدارة الأفراد:** إدارة العسكريين والرتب والترقيات والإجازات والسجلات.
- **إدارة الأقسام:** تنظيم القوات البرية والجوية والبحرية وقوات دلتا.
- **الإدارة العسكرية:** إدارة القرارات والإعلانات والطلبات والتقارير.
- **إدارة المستودعات:** متابعة المخزون والمعدات والأصول والعُهد.
- **التحقيقات:** إدارة التحقيقات والمخالفات والأدلة والعقوبات.
- **سجل التدقيق:** توثيق العمليات الإدارية والتغييرات المهمة داخل النظام.

# MACS – Military Asset Control System

**A Military Administration and Asset Management Platform**

## About the Project

MACS (Military Asset Control System) is a web-based platform designed to organize and manage military administration, personnel, departments, ranks, resources, and internal operations.

The platform aims to provide a centralized system for managing the Ministry of Defense through a public information portal and a secure internal administration dashboard.

## Main Features

- **Public Website:** Official announcements, military laws, decisions, news, and department information.
- **Authentication:** Secure login using administrator-created accounts.
- **Role-Based Access Control (RBAC):** Access permissions based on assigned roles and responsibilities.
- **Personnel Management:** Manage military personnel, ranks, promotions, leave requests, and records.
- **Department Management:** Organize Army, Air Force, Navy, and Delta Force.
- **Military Administration:** Manage official decisions, announcements, internal requests, and reports.
- **Warehouse Management:** Track inventory, equipment, assets, and custody records.
- **Investigations:** Manage investigations, violations, evidence, and disciplinary actions.
- **Audit Logs:** Record important administrative activities and system changes.

## Security

Security is a core requirement of MACS.

- Secure authentication.
- Permission-based access control.
- Restricted administrative functions.
- Database-level authorization.
- Audit logs for sensitive operations.
- Protection of confidential military information.
